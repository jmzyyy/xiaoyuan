# 发布到 GitHub

1. 登录 GitHub，创建新仓库，推荐命名 `xiaoyuan-desktop-pet`。
2. 解压本项目，将 **README.md 所在这一层的所有文件和文件夹** 上传到仓库根目录。
3. 提交文件后，README 中的 GIF 与相对链接即可显示。
4. 可创建 `v1.0.0` Release，并把项目压缩包作为附件。

本包已附好 README、素材许可证、代码许可证、图集说明和离线预览。许可证署名采用 `Xiaoyuan contributors`；你也可以在发布前将其统一替换为自己的 GitHub 昵称。

只需发布这个整理后的项目包，原始制作目录不必一同上传。

推荐仓库描述：小圆：二次元黑框眼镜桌宠，包含九组动作与十六方向透明动画素材。
推荐 Topics：desktop-pet、anime、sprite、animation、mascot。
