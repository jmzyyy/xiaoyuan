# 图集说明

最终文件：`assets/xiaoyuan-spritesheet.png`，透明 RGBA PNG。

- 总尺寸：1536 × 2288 像素
- 网格：8 列 × 11 行
- 单格：192 × 208 像素
- 已用格：73；其余 15 格完全透明
- 所有行、列均从 0 开始编号

| 行 | 状态 | 有效帧数 |
| --- | --- | --- |
| 0 | idle：待机、眨眼 | 6 |
| 1 | running-right：向右跑动 | 8 |
| 2 | running-left：向左跑动 | 8 |
| 3 | waving：挥手 | 4 |
| 4 | jumping：跳跃 | 5 |
| 5 | failed：失落与恢复 | 8 |
| 6 | waiting：期待输入 | 6 |
| 7 | running：工作、思考 | 6 |
| 8 | review：检查与认可 | 6 |
| 9 | 看向方向的前八个姿势 | 8 |
| 10 | 看向方向的后八个姿势 | 8 |

前九行从最左边依次取有效帧。每帧时长参见根目录 `sprite.json` 的 `durationsMs`。`running` 是思考工作状态。

方向以屏幕为基准：0° 向上，90° 向右，180° 向下，270° 向左，顺时针每 22.5° 一格。第 9 行是 0° 至 157.5°，第 10 行是 180° 至 337.5°。普通正面待机姿势取第 0 行。

裁剪公式：`x = column * 192`，`y = row * 208`；裁剪宽高固定为 192 × 208。播放时保留单元格内的透明边距，避免逐帧紧裁剪造成位置跳动。

## 结构检查

安装 Python 与 Pillow 后运行：

```sh
python -m pip install -r requirements.txt
python tools/check_atlas.py
```

此工具检查最终图集尺寸、透明通道、有效格与空白格；动作语义和视觉连续性还需人工查看。它不是 ChatGPT 官方导入工具。
