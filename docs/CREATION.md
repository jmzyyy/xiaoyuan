# 制作记录

小圆由经授权提供的人像参考图改编，保留深棕长发、黑框眼镜、棕色眼睛和温柔笑容。参考照片不随仓库发布。

1. 通过内置图像生成工具制作二次元 Q 版全身基础角色。
2. 使用基础角色作为身份参考，分别生成九组独立动作条。
3. 先制作上、右、下、左四个主要朝向，再生成连续的两组八方向姿势。
4. 从品红背景中提取完整姿势，用同组共享比例注册，保留跳跃的真实高度变化。
5. 统一动作间的角色尺寸与落地基线，拼成透明的 8 × 11 图集。
6. 对边缘进行一次背景溢色清理，检查透明空格、人物完整性、动作含义与转头连续性。
7. 从最终图集生成 GIF、MP4、关键帧及方向总览。

最终图集已通过本次制作流程的结构及质量检查，也通过了宠物服务的图集预检。四个主要朝向与中间朝向经过独立视觉复核。检查结果见 `reports/quality-summary.json`；将来编辑图片后需重新验证。

源图为 AI 生成的栅格 PNG，未提供分层绘画工程或 Live2D 模型。源图条保留品红背景；实际播放应使用 `assets/` 中的透明最终图集。
