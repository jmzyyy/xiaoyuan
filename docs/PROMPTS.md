# 提示词说明

基础造型：二次元 Q 版全身女孩，深棕长发、黑色圆框眼镜、棕色眼睛、温柔微笑、脸颊小痣；白色宽松上衣、深色百褶裙、白袜和深色鞋。轮廓清晰，柔和上色，无文字、标志或装饰粒子。

动作生成时附上 `source-art/character.png` 作为身份参考。每组独立生成成一行完整姿势，人物之间留出宽间距，不裁切头发或鞋子，人物大小一致，背景为纯品红 `#FF00FF`，不添加地面阴影、速度线或漂浮符号。

- idle：六帧呼吸和眨眼。
- running-right / running-left：各八帧，朝屏幕右/左跑动，交替迈腿。
- waving：四帧，手放下、抬起、挥手、收回。
- jumping：五帧，准备、起跳、最高点、下降、落地；保留实际位移。
- failed：八帧失落、低头、恢复。
- waiting：六帧期待输入，双手靠近胸前、轻微歪头。
- running：六帧专注思考，手触太阳穴，双脚保持落地。
- review：六帧扶眼镜检查，过渡到认可微笑。

转头时保持脚、裙子和下半身正面固定，让眼睛、头部、眼镜和头发自然跟随；鼻尖、下巴与眼睛共同表达方向。先制作上、右、下、左四个锚点，再以顺时针 22.5° 步进生成两行连续的八姿势。不可用整个人物旋转替代转头。

这是可复用的制作思路，不保证每次图像生成得到相同像素或姿势，生成后仍需检查和调整。
